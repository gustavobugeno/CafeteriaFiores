# Cafetería Fiores

## Descripción

Aplicación web desarrollada en Django para la gestión de pedidos de la Cafetería Fiores.

Permite:

- Inicio y cierre de sesión.
- Gestión de usuarios con roles de cliente y encargado.
- Catálogo de productos.
- Gestión de categorías.
- Gestión de productos.
- Administración de pedidos.

## Requisitos

- Python 3.12 o superior
- Django
- SQLite

## Instalación

Clonar el repositorio:

```bash
git clone https://github.com/gustavobugeno/CafeteriaFiores.git
```

Entrar al proyecto:

```bash
cd CafeteriaFiores
```

Instalar dependencias:

```bash
pip install -r requirements.txt
```

Aplicar migraciones:

```bash
python manage.py migrate
```

Ejecutar servidor:

```bash
python manage.py runserver
```

Abrir en el navegador:

```text
http://127.0.0.1:8000
```
